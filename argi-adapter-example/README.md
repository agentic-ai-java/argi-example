# argi-adapter-example

See the [root setup](../README.md) and select one capability below.

- [agentscope](agentscope/README.md): Wraps an AgentScope OpenAI-compatible model in the neutral ARGI ChatClient.
- [google-adk](google-adk/README.md): Uses the Google ADK Apigee OpenAI-compatible transport through an ARGI adapter.
- [langchain4j](langchain4j/README.md): Wraps LangChain4j chat and streaming models in the neutral ARGI ChatClient.
- [spring-ai](spring-ai/README.md): Wraps a Spring AI OpenAI-compatible model in the neutral ARGI ChatClient.
