## Additional implementation choices

- Each backend profile includes concrete starter dependencies and its actual `argi.*` properties.
- Diagram export produces PlantUML/Mermaid source without requiring a rendering service.
- Observation uses local Micrometer handlers in place of the historical external telemetry setup.
- Website snippets using removed native model/tool builders are rewritten through neutral adapters.
- Docker and sandbox samples are optional integrations; repository maintenance never starts their services.

Coverage here means source examples exist for each documented topic. It is not a claim
that every backend has been connected to or that every historical code block is retained verbatim.
See [compatibility and verification](compatibility.md).
